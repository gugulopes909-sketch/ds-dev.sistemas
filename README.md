# 💻 DS | IFPA Campus Belém

### Conheça o curso Técnico em Desenvolvimento de Sistemas!

Este projeto consiste em um site institucional desenvolvido com o objetivo de apresentar e divulgar o curso de **Desenvolvimento de Sistemas do IFPA – Campus Belém**, especialmente para os estudantes que ingressarão na instituição nos próximos anos.

A proposta é mostrar um pouco do universo da tecnologia, das possibilidades de aprendizado e das áreas de atuação que o curso oferece.

## 🚀 Objetivo do projeto

Criar uma página web informativa, moderna e acessível, capaz de despertar o interesse dos novos estudantes pela área de Desenvolvimento de Sistemas.

## 🌐 Páginas do site

- **Página inicial (`index.html`):** apresentação do curso, conteúdos estudados e informações sobre a área de Desenvolvimento de Sistemas.
- **Página de contato (`contato.html`):** espaço para apresentar informações de contato e disponibilizar um formulário demonstrativo.

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação das páginas.
- CSS3 — estilização, cores, layout e responsividade.
- Git e GitHub — versionamento e hospedagem do projeto.
- GitHub Pages — publicação do site na internet.
